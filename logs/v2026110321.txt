## 推理依据
- Command Code Provider API 的 Claude 模型只接受 `/messages`，因此 `cl gt` 不能默认 DeepSeek；`co/op/cm` 使用支持 Responses/Chat 的 DeepSeek V4.1 Flash。
- 模型 ID 含 vendor slash（`deepseek/...`），必须与 OpenCode provider prefix（`commandcode/`）分开处理。
- Command Code CLI 自身读取 `COMMAND_CODE_API_KEY`，因此只在启动器进程内从用户指定的 `COMMANDCODE_GOAT_API_KEY` 映射，避免落盘。
