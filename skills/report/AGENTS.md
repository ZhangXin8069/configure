# AGENTS.md — report 技能

本目录实现 `report` 技能：消费 analy/pure/test 的参考与证据，将科研进展、代码/物理模型和实测结果整理为面向学者、导师或同行的 16:9 横板 Beamer/PDF 科研展示。
`SKILL.md` 是流程权威；`references/report-guide.md` 规定逐页叙事、视觉选型与信息密度，`references/latex-template.md` 规定模板和防溢出验收。
执行时保留证据清单与编译结果；有 Git 改动时按上级 `AGENTS.md` 执行 `git diff --check`，不自动暂存、提交或推送。
