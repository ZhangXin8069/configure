# auto — 全自动前缀执行技能

## TODO 管理（全局约定）

执行第一步用 **todowrite 工具**生成**详细 TODO 列表**：按任务分解为可独立验证的
子步骤、按依赖排序；**每完成一个子步骤立即调用 todowrite 更新状态**（进行中/完成）；
收尾时核对全部完成。约定全文见 `skills/AGENTS.md`「TODO 生成与实时更新约定」。

以 `~auto-<目标技能> <任务>` 为前缀包装任意技能为**无人值守模式**：唯一的一次用户交互
发生在启动时（权限+配置一次性预授权），此后严格 0 交互，自动循环调用目标技能及其
子技能链直至收敛，只有强制中断（Ctrl+C / `~stop`）才会停止。

## 核心原则

1. **前缀式包装，不重复实现**：auto 不复制任何目标技能的细节流程，以 `~auto-<skill>`
   前缀驱动目标技能（all/make/debug/optim/test/...），细节以目标技能 SKILL.md 为权威
   （吸收 all 的"编排层不重复发明细节"原则）。
2. **一次性预授权（全程唯一的交互）**：启动即请求"本次任务全部权限 + 全部配置"，
   授权按级别分级（L1 全授权含破坏性 / L2 常规授权 / 自定义清单），配置含工作目录、
   轮数上限、停滞阈值、收尾动作；用户确认后写入会话日志，本任务不再有任何请求。
3. **0 交互承诺**：预授权后不发起任何形式的用户请求（不提问、不确认、不征询）；
   目标技能流程中的"需确认/需询问"步骤一律按预授权配置自动决定
   （L1 直接执行；L2 跳过并记录；自定义按配置项执行）。
   **0 交互 ≠ 0 报告**：每轮简报、停滞报告、中断报告、最终汇总照常输出。
4. **自动循环直至收敛**：复用 all 的收敛判据（①通过标准全部达成 ②收益 <5%
   ③连续两轮无实质变化 ④用户终止），每轮留证据（`$ 命令` + 退出码 + 实测输出），
   收敛后自动进入收尾，不空转。
5. **无限循环与停滞保护并存**：默认无轮数上限（除非启动配置 max_rounds）；
   停滞保护防空转——连续 N 轮（默认 3）无实质进展时自动**换方向**（先 debug 后 optim，
   一轮一动作）；三个不同方向均无进展时输出停滞报告并继续尝试新方向，
   除非配置 stop_on_stall=true（默认 true，避免无限空转烧资源）。
6. **强制中断随时生效**：Ctrl+C / 用户输入 `~stop`/`中断`/`停止`/新指令 → 立即停止
   循环并产出中断报告（进度/已改动/遗留/恢复方式）；每轮开始前检查中断信号。
7. **收敛后自动收尾**：按启动配置执行 diff 复查（--check）→ init 归集（如产物为
   agent 生成内容）→ tag 打标（如配置启用）→ 汇总输出；全部自动化，不询问。
8. **诚实原则不豁免**：0 交互不豁免验证——每轮结论以实测为证（退出码/数值/输出），
   无法验证的项标注原因；不虚报收敛与收益；授权范围之外的操作一律不做。
9. **安全边界**：权限请求只收集本次任务所需，不索取无关权限；不修改系统/工具的
   权限配置（预授权是会话内约定，落地为"本会话不再询问"）；破坏性操作仅按
   预授权级别执行（L2 自动跳过并记录）。

## 会话日志

每次 auto 会话必须在**当前工作目录（仓库根）**生成详细日志：

- 文件名格式：`.auto.<时间戳>.log`（例如 `.auto.2026-08-14-03-35-00.log`）
- 时间戳格式：`%Y-%m-%d-%H-%M-%S`：`TS=$(date +%Y-%m-%d-%H-%M-%S)`
- 日志**不入库**（与仓库 `.all.*.log`、`.agent.*.log` 约定一致），全程**追加**写入（`>>`）
- 记录内容（**会话头**）：开始时间、工作目录、git 分支与 HEAD、解析出的目标技能与
  任务定义、预授权清单（级别/权限项/配置项）与用户确认结果；
- 记录内容（**过程**）：每轮迭代（`---- [时间] 第 N 轮 ----` + 评估结论/改动/复测数据）、
  停滞检测与换方向记录、中断信号与中断报告、子技能会话日志关联路径；
- 记录内容（**会话尾**）：收敛判据达成明细、收尾结果（diff/init/tag）、最终汇总、
  遗留项、结束时间与总耗时。

**记录规范**：关键事件以分隔行标记 `---- [YYYY-MM-DD HH:MM:SS] 事件描述 ----`；
命令统一记作 `$ <命令>` 并在结果行标注退出码；全程不覆盖、只追加。

## 历史日志预读（关键信息速览）

会话**第一步**只读预读本技能**最新一份**历史日志的**尾部汇总区**（只关注关键信息，不做深入解析）：

```bash
tail -20 "$(ls -1t .auto.*.log 2>/dev/null | head -1)"   # 尾部汇总区：上次任务/结论/遗留项
```

- 关键信息：① 上次任务/对象；② 结论或收敛结果；③ 遗留项与下一步建议——其余（过程轮次、命令细节）一律跳过，不做深入 think
- 约束：只读不改；无历史日志（首次运行）时正常跳过，不视为错误；总耗时以秒级为限

### 前置上下文预读（工作目录说明文件与 agent 文件夹）

会话**第一步**与历史日志预读同步执行：只读当前工作目录的**说明文件**与 **agent 文件夹**
（清单可扩展，存在即读、缺失即跳过，不视为错误），只取关键信息、避免耗时过长：

```bash
# 1) 说明文件（按优先级取第一个存在的：AGENTS.md > README.md > CLAUDE.md > AGENT.md > CODEX.md）
for f in AGENTS.md README.md CLAUDE.md AGENT.md CODEX.md; do
  [ -f "$f" ] && { echo "== $f =="; head -40 "$f"; break; }
done
# 2) agent 文件夹（按优先级取第一个存在的：.opencode > .claude > .codex）
for d in .opencode .claude .codex; do
  [ -d "$d" ] || continue
  echo "== $d =="; ls "$d" | head -10
  [ -f "$d/AGENTS.md" ] && head -20 "$d/AGENTS.md"
  break
done
```

- 关键信息：项目约定/命令/目录结构/入口点/测试方式；agent 文件夹只列顶层结构（如 AGENTS.md、skills/）
- 约束：只读不改；文件/目录不存在时正常跳过；`head` 限行保证秒级耗时

### AGENTS.md 同步（必要时补充有益内容）

会话中如发现**当前工作目录的 AGENTS.md** 缺失本次任务相关且对后续会话有益的内容
（项目约定/命令/目录结构/入口点/测试方式/新功能说明），**必要时补充更新**，
保持约定文档与仓库状态同步：

- 只补充**确凿有益**的内容：本次任务确立的约定、验证过的命令、新入口点/结构变化；
  不写入个人化/临时性/未验证内容；
- **最小改动**：在既有章节内补充或新增小节，遵循原文档结构（表格/列表），不重写全文；
- **先读后写**：写入前先读 AGENTS.md 现状，避免重复条目与格式破坏；
- 补充位置与内容记入会话日志；改动不代提交（提示用户自行 git add/commit）。

## 触发时机

- 用户以前缀形式触发：`~auto-<技能名> <任务>`（如 `~auto-all 优化xxx`、
  `~auto-make 做一个xxx`、`~auto-debug 修复xxx`）
- 用户要求全自动执行："全自动"、"无人值守"、"自动执行"、"一口气做完"、
  "做完为止"、"不要问我"、"无限循环"、"跑完为止"、"搞定为止"
- 与其他技能配合：目标技能未指定 → 默认 all（全流程收敛编排）；
  目标技能不存在 → 启动时列出候选供一次性确认；
  纯单步任务（debug/optim/test/analy）→ 直接以单技能为目标的 auto 模式；
  多独立子任务 → ~auto-dispatch 并行派发（子代理批量执行后整合）
- 不适用：任务需要持续人工决策/评审（如内容创作风格、架构评审）→ 用对应技能常规模式

## 工作流程

### Step 0. 解析前缀与任务

```text
输入: ~auto-<target> <task>
target = 前缀中的技能名（all/make/debug/optim/test/analy/diff/tag/init/plan/review/
         tdd/skill-creator/up/dispatch/auto 之一）；缺省默认 all
task   = 前缀后的完整任务描述
```

- target 不在技能表 → 在 Step 1 的清单中列出候选技能供用户一次性选择（唯一交互窗口）；
- 记录目标技能与任务定义到会话日志。

### Step 1. 一次性授权与配置收集（唯一交互）

输出如下清单并请求**一次**确认（此后不再有任何请求）：
**原则：第一次请求必须问全**——预授权清单一次性覆盖本次任务可能产生的所有用户请求
（含 [3] 中按目标技能预判的全部配置项），严禁分批提问、事后补问。

```text
=== ~auto-<target> 预授权清单 ===
任务: <task>
目标技能: <target>（将调用其子技能链: <推断的链>）

[1] 授权级别（必选）:
  L1 全授权 —— 含破坏性操作（删除文件/改写已推送标签/force push），按需执行
  L2 常规授权 —— 常规操作（bash/文件写/git 提交与推送/tag/网络/长时运行）；
                破坏性操作跳过并记录    ← 默认
  自定义 —— 在下方注明放行/禁止项

[2] 关键配置:
  工作目录: <当前目录/指定目录>
  收敛判据: 继承目标技能（通过标准全达成 + 收益<5% + 连续2轮无实质变化）
  停滞阈值: 连续 <3> 轮无实质进展即换方向; 方向穷尽后 stop_on_stall=<true>
  轮数上限: <无限/指定 N>
  收尾动作: diff(必做) / init(按需) / tag(按需)
  中断指令: Ctrl+C 或输入 ~stop/中断/停止

[3] 本次任务的明确配置项（由任务性质决定，如测试设备/精度、目标路径等）:
  <按目标技能需预收集的配置，列于此>

请确认（输入 Y / 选择级别或调整后确认 / N 取消）：
```

- 用户确认后：授权级别与全部配置写入会话日志，**进入 0 交互模式**；
- 用户取消（N）→ 结束会话，不执行任务。

### Step 2. 0 交互驱动目标技能

按目标技能 SKILL.md 执行，全程不发起请求：

- target=all → 以预配置的收敛判据驱动全流程编排（其内部再调用各子技能）；
- target=make → 单次全流程生成（解析需求→调查规划→实现→测试→优化→复查→归档→打标）；
- target=其他单技能 → 按该技能 SKILL.md 执行；
- 目标技能流程中出现"需用户确认"步骤 → 按预授权自动决定：
  L1 直接执行；L2 跳过并记录；自定义按配置项执行——**不中断、不提问**；
- 每次调用子技能记录其会话日志路径（`.debug.*.log` 等）到 auto 日志。

### Step 3. 自动循环与停滞保护

目标技能自身有循环（all）时以之为准；无循环（单技能）且任务未收敛时按如下循环：

1. 每轮开始：检查中断信号（用户新指令/Ctrl+C/`~stop`）→ 有则进入 Step 5 中断收尾；
2. 执行 → 验证 → 记录（`$ 命令` + 退出码 + 实测输出）；
3. 收敛检查（判据：通过标准全达成 / 收益<5% / 连续 2 轮无实质变化）→ 满足则进入 Step 4；
4. 未收敛：评估本轮主导问题（失败→debug 轮；性能→optim 轮；修复与优化分轮）；
   连续 N 轮（停滞阈值，默认 3）无实质进展 → 换方向（先 debug 后 optim）；
   三个不同方向均无进展且 stop_on_stall=true → 输出停滞报告并停止循环进入 Step 4
   （记录"方向穷尽"证据）；stop_on_stall=false → 继续换方向尝试；
5. 轮数达上限（如配置）→ 停止，报告权衡，进入 Step 4。

### Step 4. 收尾（自动化）

按启动配置依次执行，全程不询问：

1. **改动复查**（diff）：`git diff --check` + `git diff --stat` 概览 + 逐文件详情；
   边界校验（冲突标记/调试残留/未跟踪/二进制/重命名）；
2. **skill 归集**（init，配置启用时）：agent 生成内容对应的完整 skill 归集到技能库；
3. **版本标签**（tag，配置启用时）：先看后打，注释标签消息格式
   `follow <前一标签>, 1. 变更一; [opencode].`；推送按 tag 技能默认执行；
4. **不代提交**：涉及 git 跟踪文件时在汇总中提示用户自行 `git add` + 提交。

### Step 5. 中断与恢复

收到中断信号（Ctrl+C / `~stop` / 新指令）时：

1. 立即停止当前循环（不启动新一轮）；
2. 产出**中断报告**：已完成进度、本轮已改动（`文件:行号`）、遗留项、恢复方式
   （下次从何处继续、`.auto.<时间戳>.log` 中第几轮为断点）；
3. 不执行未预授权的收尾动作（如 tag）——中断即终止，收尾仅做 diff 复查与汇总。

### Step 6. 汇总（结构化输出）

```text
✓ auto 执行完成/中断
   目标:   <target> / <task>
   授权:   <级别 L1/L2/自定义 + 关键配置摘要>
   收敛:   <判据达成明细 / 中断原因 / 停滞报告摘要>
   轮数:   <N 轮（第 N 轮: <结论>; ...）>
   改动:   <文件清单与关键改动>
   子技能: <各子技能会话日志路径>
   标签:   <tag 结果，无则省略>
   遗留:   <未收敛项/待用户确认项/恢复建议>
   日志:   .auto.2026-08-14-03-35-00.log
```

**声明前自检**：输出"收敛/完成"前逐项核对——每个结论均有**本次会话刚运行**的
验证输出（退出码/数值）为证；缺失证据的项改为"未验证"或补跑后更新。

## 错误处理

| 场景 | 处理 |
|---|---|
| 前缀目标技能不存在 | Step 1 清单中列出候选技能，用户一次性选择后继续（唯一交互窗口内解决） |
| 用户取消预授权 | 结束会话，不执行任务 |
| 目标技能强制要求交互（如 brainstorm HARD-GATE） | 预授权模式跳过批准闸门，决策记录到会话日志；用户可在 Step 1 配置为"仍要求该步骤交互" |
| 停滞且方向穷尽 | 输出停滞报告（证据：各方向改动与收益）；stop_on_stall=true 停止，false 继续换方向 |
| 中断信号 | 立即停止循环，产出中断报告（进度/改动/遗留/恢复方式） |
| 破坏性操作未预授权（L2） | 跳过并记录到日志，不执行 |
| 网络失败/超时 | 按目标技能错误处理（debug 循环重试/换源），重试记入日志 |
| 轮数达上限 | 停止，报告权衡与证据 |
| 用户中途改目标 | 视为中断+新任务：输出中断报告后重新解析前缀，重置轮数 |
| 0 交互模式下证据缺失 | 不宣称完成；补跑验证或标注"未验证"，如实报告 |

## 注意事项

- auto 是前缀包装器：不重复实现目标技能的细节流程，细节以各技能 SKILL.md 为权威；
- 0 交互 ≠ 0 报告：每轮简报、停滞/中断报告、最终汇总照常输出（报告不是请求）；
- 权限请求只收集本次任务所需，不索取无关权限；不修改系统/工具的权限配置；
- 破坏性操作只在本会话内按预授权级别执行；不代提交代码；
- 不越界访问工作目录之外的内容；
- 会话日志 `.auto.<时间戳>.log` 不入库，由用户决定保留或清理。
