[WARN] zda: 未找到 miniforge3 的 conda base 环境，无法激活。
安装 Miniforge（清华 TUNA 镜像，国内比 GitHub 原地址稳定）：
  base=https://mirrors-i.tuna.tsinghua.edu.cn/github-release/conda-forge/miniforge/LatestRelease
  wget -O /tmp/Miniforge3-Linux-x86_64.sh "$base/Miniforge3-Linux-x86_64.sh"
  bash /tmp/Miniforge3-Linux-x86_64.sh        # 安装路径保持默认 $HOME/miniforge3
  exec bash
切换 conda-forge 镜像并清理索引缓存：
  conda config --remove channels conda-forge 2>/dev/null || true
  conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/
  conda config --set show_channel_urls yes
  conda clean -i
让登录 shell 自动加载 conda（按实际 shell 选择，可两条都执行）：
  conda init bash
  conda init zsh

以上只是最小可用环境。zda 假定 base 里已装好下面这套开发工具链，缺任一项时
zda 仍会激活，但路径变量只能覆盖实际存在的目录。

1) 工具链（在 base 中执行）：
  mamba update -n base -c conda-forge conda
  mamba install conda-self zsh gfortran gxx make cmake htop btop nvtop netwatch tree nodejs \
    "cuda-version=12.4.0" "cuda-nvcc" "cuda-libraries-dev" "cuda-nvml-dev" \
    "cuda-nvvp" "cuda-gdb" "python=3.12.4" "hdf5=2.2.0=mpi_openmpi*" cupy

2) CUDA/HDF5 派生变量（base 激活后写入 env.sh 或 shell 启动文件）：
  export CUDA_PATH="${CONDA_PREFIX}/targets/x86_64-linux"
  export CPLUS_INCLUDE_PATH="${CUDA_PATH}/include":${CPLUS_INCLUDE_PATH}
  export PATH="${CONDA_PREFIX}/nvvm/bin":${PATH}
  export HDF5_MPI="ON"
  export HDF5_DIR="${CONDA_PREFIX}"

3) 需要与 conda MPI/HDF5 匹配的 Python 包（源码编译）：
  python -m pip install --upgrade pip
  pip install mpi4py --no-binary=mpi4py --no-cache-dir
  pip install h5py --no-binary=h5py --no-cache-dir
  pip install tilelang --no-binary=tilelang --no-cache-dir
  pip install torch torchvision --no-binary=torch --no-cache-dir
  pip install scipy cython seaborn opt_einsum lsqfit
  编译前确认 mpicc/mpicxx/h5cc 均来自 base：command -v mpicc mpicxx h5cc

4) TeX 用系统包（conda-forge 的 texlive-core 太简陋）：
  sudo apt install texlive-xetex

5) 验证：
  command -v conda && conda --version
  conda activate base && printf '%s\n' "$CONDA_PREFIX"
  command -v python pip gcc nvcc h5cc mpicc
  nvcc --version | tail -2
  python -c 'import h5py, mpi4py; print(h5py.__version__, mpi4py.__version__)'
